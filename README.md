# EduPract.01
# Менеджер паролей

Локальное desktop-приложение для хранения учётных данных, генерации паролей и поиска записей. Данные хранятся в SQLite, пароли шифруются ключом из мастер-пароля.

## Технологии
Python 3.10+, Tkinter, SQLite, cryptography, pytest

## Установка
```
pip install -r requirements.txt
```

## Запуск приложения
Из корневой папки репозитория:
```
python -m src
```
При первом запуске программа предложит создать мастер-пароль. Восстановить его нельзя, поэтому запомните его.

Файл базы создаётся в домашней папке: `~/.password_manager/vault.db`. В репозиторий он не попадает.

## Тесты
```
python -m pytest
```

## Структура
- docs/ документация по дням (day1-2, day3, day4, day6)
- src/core/ ядро: модель записи, генератор, надёжность, маскирование, поиск, шифрование
- src/data/ слой данных: SQLite, репозиторий записей, хранилище с мастер-паролем
- src/system/ системные механизмы: буфер обмена с автоочисткой
- src/ui/ интерфейс Tkinter: вход, список, форма, детали, валидация
- src/__main__.py точка входа (`python -m src`)
- tests/ тесты
- assets/ изображения
