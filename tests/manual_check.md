## Подготовка
```
pip install -r requirements.txt
python -m pytest
python -m src
```
Перед проверкой удалите старый файл хранилища (`~/.password_manager/vault.db`) или запустите проверку под отдельным пользователем, иначе экран будет «Вход», а не «Создание».

## Основной путь
1. Создать хранилище мастер-паролем. Проверить UI-01...UI-03.
2. Добавить две записи: одну через генератор, одну вручную. Проверить UI-06, UI-09, UI-11.
3. Открыть запись, показать и скрыть пароль (UI-13). Скопировать пароль (UI-19).
4. Изменить запись (UI-14), удалить вторую (UI-15, UI-16).
5. Поиск по части названия и по несуществующей строке (UI-17, UI-18).
6. Нажать «Выйти», войти заново с неверным и верным паролем (UI-05, UI-21).
7. Закрыть окно и открыть снова (UI-12).
