## Сценарий «сохранение, перезапуск, загрузка»
Запускайте каждый блок отдельной командой python, чтобы имитировать перезапуск.

Шаг 1, создание и добавление:
```
python -c "from src.data.vault import Vault; from src.core.models import Entry; v=Vault('tmp_check.db'); r=v.create('manual-master'); r.add(Entry(service='Test', login='me', password='Abc123!xyz')); v.close()"
```
Шаг 2, новый запуск и чтение:
```
python -c "from src.data.vault import Vault; v=Vault('tmp_check.db'); r=v.unlock('manual-master'); print(r.list_all()); v.close()"
```
Шаг 3, неверный пароль (ожидается «Неверный мастер-пароль.»):
```
python -c "from src.data.vault import Vault; v=Vault('tmp_check.db'); v.unlock('wrong')"
```
Шаг 4, содержимое файла: открыть tmp_check.db в любом просмотрщике (например DB Browser for SQLite) и убедиться, что пароль `Abc123!xyz` нигде не читается.

После проверки удалить tmp_check.db и не добавлять его в Git.
