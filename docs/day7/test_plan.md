Автор: Шипунов Е. А. (тестировщик)
Версия сборки: день 6 + исправления дня 7 (ветка day7-dev-mahnev)

## 1. Что тестируем
| Модуль | Что проверяем | Требования ТЗ |
|---|---|---|
| src/core (генератор, надёжность, маскирование, поиск, шифрование) | корректность функций, граничные значения | M4, M5, M6, M7, S2 |
| src/data (хранилище, записи, мастер-пароль) | создание, вход, CRUD, поведение при ошибках | M1, M2, M3, M4 |
| src/system/clipboard.py | копирование и очистка буфера | S1 |
| src/ui (вход, список, форма, детали, валидация) | сценарии пользователя через окно | US-1...US-8, NFR раздела 5 |

Вне тестирования: смена мастер-пароля (S3), экспорт и импорт (C1), автоблокировка (C2), мобильная версия (ТЗ, раздел 3.4 «Won't»).

## 3. Подходы
1. Чёрный ящик: 12 тест-кейсов по сценариям пользователя (test_cases.md).
2. Граничные значения: пустой ввод, пробельные строки, длина 7/8/64/65, строки 1000, 3000, 5000 и 20000 символов, юникод, спецсимволы в поиске.
3. Повторные действия: повторное «Сгенерировать», повторное «Сохранить».
4. Unit-тесты: 37 тестов для пяти ключевых функций (tests/test_unit_day7.py). Тесты не используют файлы, БД и Tk, выполняются меньше 0,1 с.
5. Сценарный прогон окна на виртуальном дисплее (docs/day7/tools/manual_probe.py). Это автоматизированный прогон сценариев, а не работа живого человека с интерфейсом.

## 4. Критерии
- Вход в тестирование: сборка дня 6 проходит pytest (64 теста).
- Выход из тестирования: 0 открытых Blocker и Critical; все тест-кейсы прогнаны повторно после исправлений; unit-тесты проходят.
- Серьёзность: Blocker (программа не запускается или теряет данные), Critical (падение или утечка секрета), Major (неверное поведение основной функции), Minor (косметика или неудобство).

- Не проверен Windows, а ТЗ требует Windows 10/11. Поведение Tk на Windows может отличаться, в том числе по размеру надписей и буферу обмена.
- Скриншоты падающего окна не получены: процесс завершается до отрисовки. В баг-репорте приложен текст ошибки X11.
- Ручного прогона живым пользователем не было, сценарии выполнены скриптом.
- Blocker не найдено. Серьёзный дефект (BUG-01) исправлен, но тест на Windows остаётся открытым риском.
