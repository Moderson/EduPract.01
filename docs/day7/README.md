# Инструмент сценарного прогона

Файл manual_probe.py выполняет 18 сценарных проверок окна через Tkinter. Запуск из корня репозитория:

```
xvfb-run -a python docs/day7/tools/manual_probe.py
```

Переменная SKIP со списком имён функций (например, SKIP=t_long_service) пропускает шаги. Используется только для воспроизведения результатов до исправления.
Скрипт пишет в домашнюю папку тестовые записи. Запускайте его с временным HOME: `HOME=/tmp/probe xvfb-run -a python ...`.
