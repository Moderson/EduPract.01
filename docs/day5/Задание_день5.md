## Правка .gitignore (руководитель)
Откройте .gitignore на сайте, нажмите карандаш и допишите в конец файла:
```
# Файлы баз данных
*.db
*.db-journal
*.sqlite3
*.sqlite3-journal
```
Коммит: `chore: файлы SQLite добавлены в .gitignore`.

## Примечание о нумерации
В методичке дней 4-5 путь и тег указаны как docs/day3 и day3. Используем docs/day4 и тег day4, чтобы не повторять тег дня 3.

## Порядок работы с Git
1. Ветки day4-* создаются от feature после слияния дня 3.
2. Каждый коммитит только свои файлы в свою ветку.
3. Pull Request каждой ветки в feature (Create a merge commit), порядок: Тумин → Бабаревич → Махнев → Шипунов.
4. Pull Request feature в main, затем релиз с тегом day4.
5. Тестировщик запускает `python -m pytest` после слияния ветки разработчика и заполняет колонки «Факт» и «Статус».
