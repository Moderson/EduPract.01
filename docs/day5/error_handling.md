# Обработка ошибок слоя данных (день 4)

Все ошибки слоя данных наследуются от `DataError` (src/data/errors.py). Текст исключения предназначен для показа пользователю. Технические подробности пишутся в журнал, пароли и мастер-пароль в журнал не попадают.

| № | Ситуация | Исключение | Сообщение пользователю | Реакция | Тест |
|---|---|---|---|---|---|
| 1 | Папка для файла БД не существует | нет, обрабатывается | нет | папки создаются, БД открывается | DT-20 |
| 2 | Файл по пути БД не является базой SQLite | StorageError | Не удалось открыть файл базы данных. Проверьте путь, права доступа и что файл не повреждён. | соединение закрывается, ошибка в журнале | DT-21 |
| 3 | Путь к БД указывает на папку | StorageError | то же | то же | DT-22 |
| 4 | Нет прав на запись или диск недоступен | StorageError | то же | то же | ручной сценарий 5 |
| 5 | БД занята другим процессом | StorageError через 5 с ожидания | Ошибка работы с базой данных. Повторите операцию. | транзакция откатывается | не покрыто |
| 6 | Хранилище ещё не создано | VaultNotInitialized | Хранилище ещё не создано. Задайте мастер-пароль. | UI показывает окно создания | DT-03 |
| 7 | Хранилище уже создано | VaultAlreadyInitialized | Хранилище уже создано. Введите мастер-пароль для входа. | UI показывает окно входа | DT-04 |
| 8 | Пустой мастер-пароль | ValidationError | Мастер-пароль не может быть пустым. | хранилище не создаётся | DT-05 |
| 9 | Неверный мастер-пароль | WrongMasterPassword | Неверный мастер-пароль. | вход запрещён, в журнале предупреждение без пароля | DT-02, DT-24 |
| 10 | Пустое название сервиса | ValidationError | Название сервиса не может быть пустым. | запись не сохраняется | DT-11 |
| 11 | Пустой пароль записи | ValidationError | Пароль не может быть пустым. | запись не сохраняется | DT-12 |
| 12 | Изменение записи без номера | ValidationError | Нельзя изменить запись без номера. | ничего не меняется | DT-13 |
| 13 | Запись с таким номером не найдена | EntryNotFound | Запись с номером N не найдена. | данные не меняются | DT-10 |
| 14 | Токен пароля в БД испорчен или зашифрован другим ключом | StorageError | Запись N повреждена или зашифрована другим ключом. | чтение этой записи прерывается, ошибка в журнале | DT-23 |
| 15 | Хранилище пустое | нет | нет | возвращается пустой список | DT-18 |
| 16 | Ошибка при записи в буфер обмена | исключение функции set_text пробрасывается | сообщение формирует UI (дни 5-6) | таймер очистки не запускается | не покрыто |

## Пока не покрыто
Строки 5 и 16 описывают предусмотренное поведение, но автоматических тестов на них нет. Строку 4 проверяет тестировщик вручную.

## Журнал
Модули пишут в `logging.getLogger(__name__)`. Настройка обработчика (файл или консоль) выполняется один раз при старте приложения на днях 5-6. Тест DT-24 проверяет, что в журнале нет паролей записей и мастер-пароля.
