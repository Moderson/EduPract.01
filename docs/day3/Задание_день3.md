## Результат дня
Ядро импортируется как пакет `src.core`, функции из контракта (architecture.md) работают, ручная проверка выполнена, на main стоит тег `day3`.

## Не входит в день
SQLite (день 4), интерфейс Tkinter (дни 5-6), полный набор unit-тестов (день 7).

## Порядок работы с Git
1. Ветки day3-* создаются от feature.
2. Каждый коммитит только свои файлы в свою ветку.
3. Pull Request каждой ветки в feature (Create a merge commit).
4. Pull Request feature в main, затем релиз с тегом day3.
